The reticle map shown here was only the first iteration and required some changes by GF:

- The halo for the seal ring around the die is actually 26um and not 25um. The seal ring is 16um wide, and there needs to be a 10um space. Therefore, the design die size is: 3880x5070um. The sealring adds 26um on all sides for: 3932x5122um
- The scribe width is 60um on all sides (I assume everything moves to the bottom left corner).
